## Остаточные риски и рекомендации

1. **🔴 GitHub-токен в `git remote`** (локальный `.git/config`, НЕ в истории):
   - Ротировать токен на GitHub (Settings → Developer settings → Personal access tokens → Revoke `ghp_bOCc…`).
   - Очистить URL: `git remote set-url origin https://github.com/intulint/pi-websearch.git`
   - Далее использовать credential helper или SSH.
2. **🟠 Nested undici в `@earendil-works/pi-coding-agent@0.83.0`** (2 high) — отслеживать обновления фреймворка; расширение использует собственную undici 7.29.0 без уязвимостей, поэтому runtime-риск низкий.
3. **🟡 Логи** (`~/.pi/logs/pi-websearch/tool_calls.log.json`) — могут содержать ПДн из поисковых запросов/контента; при необходимости — права 600 и/или очистка.
4. **🟡 Опционально:** in-memory кэш DDG-результатов (~30 с) для снижения rate-limit; ESLint при росте кодовой базы.
